# EventKita - Platform Pendaftaran dan Manajemen Event

Aplikasi web berbasis Laravel 13 untuk tugas kuliah. Memungkinkan User untuk mendaftar event dan Admin untuk mengelola event serta memverifikasi pendaftar.

## 🛠️ Teknologi yang Digunakan
*   **Framework:** Laravel 13 (PHP 8.4)
*   **Database:** MySQL
*   **Frontend:** Tailwind CSS, Vanilla JavaScript, Vite
*   **Environment:** Laravel Herd
